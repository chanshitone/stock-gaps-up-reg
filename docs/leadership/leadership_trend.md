# 为什么不是只看当天得分？

单日分数容易被热点扰动。

比如某个申万三级行业今天涨停潮：

```text
RS_20 突然变强
Volume_Ratio 放大
Above_MA20 上升
```

单日分数可能很高。

但它可能只是：

```text
热点
不是题材
更不是主线
```

主线的核心是**持续性**，所以你要看趋势线，而不是只看单日值。

---

# 不同时间窗口分别看什么？

## 1. 5日：看短期热度

```text
Score_MA5 = 最近5日行业得分均值
```

它回答：

> 这个方向最近一周是不是突然活跃？

适合识别：

```text
热点启动
题材发酵
短期回流
反抽
```

但 5 日太短，不能确认主线。

---

## 2. 10日：看题材是否持续

```text
Score_MA10 = 最近10日行业得分均值
```

它回答：

> 这个方向是不是已经从热点变成题材？

如果一个方向：

```text
Score_MA5 上升
Score_MA10 也开始上升
```

说明不是单日脉冲，可能正在形成题材。

---

## 3. 20日：看是否具备主线基础

```text
Score_MA20 = 最近20日行业得分均值
```

它回答：

> 这个方向过去一个月是否持续被市场认可？

主线至少要看 20 个交易日。

如果：

```text
Score_MA20 > 70
并且 Score_MA5 > Score_MA10 > Score_MA20
```

说明主线正在加速。

如果：

```text
Score_MA20 仍高
但 Score_MA5 < Score_MA10
```

说明短期可能开始降温。

---

## 4. 60日：看中期主线地位

```text
最近60日趋势线
```

它回答：

> 这个申万三级行业是不是过去一整个季度的市场领导方向？

你原来的指标里有 RS_60，所以展示 60 日很合理。

60 日适合判断：

```text
主线形成
主线分化
主线退潮
主线重新激活
```

---

## 5. 120日：做历史背景

```text
保存最近120日得分
```

它回答：

> 当前得分在过去半年处于什么位置？

比如：

```text

```

如果过去半年最高只有 80，那它已经很强。
如果过去半年经常 90，现在 78 可能已经降级。

所以 120 日适合做：

```text
历史分位
趋势背景
主线生命周期判断
```

说明：
