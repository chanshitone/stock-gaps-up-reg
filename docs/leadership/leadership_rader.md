下面给你一个适合 **A股趋势系统 / Sector Radar** 的版本。

核心思路：

> **大周期主线 = 长期产业地图**
> **主线 = 当前市场领导方向**
> **题材 = 活跃交易主题**
> **热点 = 短期资金兴奋点**

它们不是四个完全独立的东西，而是一个“时间周期 + 资金强度 + 价格持续性”的分层系统。

---

# 1. 四个概念的定义

## 一、热点 Hot Spot

**定义：**

> 热点是短时间内因为消息、政策、事件、情绪刺激，资金突然集中交易的方向。

特点：

```text
时间短：1–3 天
爆发快：涨停、大阳线、成交额突然放大
持续性弱：容易一日游
验证不足：未必有龙头持续新高
```

例子：

```text
某个政策消息刺激
某个产品发布会
某个新闻事件
某个板块当天涨停潮
```

热点的本质是：

> **资金短期兴奋。**

它对你系统的作用是：**发现新方向，但不能直接追。**

---

## 二、题材 Theme / Thematic Play

**定义：**

> 题材是有清晰故事、催化剂或产业逻辑，并且能维持几天到几周交易热度的方向。

特点：

```text
时间：3–15 个交易日，甚至更长
有故事：政策、产业、技术、订单、涨价、事件
有扩散：不止一只股票上涨
但未必成为主线
```

例子：

```text
HBM
CPO
低空经济
机器人
液冷
玻璃基板
AI眼镜
脑机接口
```

题材的本质是：

> **有叙事的短中期交易机会群。**

它对你系统的作用是：**扩大候选池，判断资金扩散。**

---

## 三、主线 Market Leadership / Leading Sector

**定义：**

> 主线是在一段时间内持续强于市场、资金反复回流、龙头持续创新高、板块内部不断扩散的核心方向。

特点：

```text
时间：数周到数月
有龙头
有中军
有补涨
有反复
有资金共识
回调后还能回来
```

例子：

```text
AI算力链
新能源车产业链
半导体国产替代
光模块/CPO
存储/HBM
先进封装
```

主线的本质是：

> **市场当前最愿意持续给钱的方向。**

它对你系统的作用是：**信号排序和提高交易质量。**

---

## 四、大周期主线 Secular Trend / Mega Trend

**定义：**

> 大周期主线是由长期产业变革、技术革命、政策战略、社会结构变化驱动的多年级别方向。

特点：

```text
时间：1–5 年，甚至 10 年
长期逻辑强
中间会有多轮上涨、回调、休眠、再启动
不等于每天都能买
```

例子：

```text
AI
新能源
国产替代
数字经济
人口老龄化
军工自主可控
机器人/具身智能
```

大周期主线的本质是：

> **长期产业地图。**

它对你系统的作用是：**维护长期观察池，而不是直接决定买卖。**

---

# 2. 四者关系

可以这样理解：

```text
热点
  ↓ 如果持续
题材
  ↓ 如果有龙头、扩散、反复回流
主线
  ↓ 如果背后有多年产业趋势
大周期主线
```

但也可以反过来：

```text
大周期主线：AI
  ↓
主线：AI算力硬件
  ↓
题材：光模块 / HBM / CPO / 先进封装
  ↓
热点：某天 CPO 涨停潮
```

所以它们不是互斥关系，而是不同层级。

# 3. 最重要的区分维度

| 维度      |   热点 |    题材 |    主线 |  大周期主线 |
| ------- | ---: | ----: | ----: | -----: |
| 时间周期    | 1–3天 | 3–15天 | 数周到数月 |     数年 |
| 资金持续性   |    弱 |     中 |     强 |   长期反复 |
| 是否有龙头   |  不一定 |   可能有 |   必须有 |    会轮换 |
| 是否有板块扩散 |  不一定 |     有 |   必须有 |  多阶段扩散 |
| 是否可直接交易 |   谨慎 |  可以观察 |   最适合 | 不可直接交易 |
| 对你系统作用  |   预警 |   候选池 |  排序加分 |   长期地图 |

# 4. 量化框架：四个核心维度

你可以用四类指标量化：

```text
1. Strength：强度
2. Breadth：广度
3. Persistence：持续性
4. Leadership：龙头性
```

再加两个辅助指标：

```text
5. Liquidity：成交额/资金容量
6. Resilience：抗跌与修复能力
```

也就是：

```text
主线评分 =
强度 + 广度 + 持续性 + 龙头性 + 成交额 + 抗跌修复
```

# 5. 指标设计

下面是可以直接编码的指标。

---

## A. 强度 Strength

看这个方向是否强于市场。

### 指标 1：方向相对强度 RS

```text
RS_20 = 板块20日涨幅 - 基准20日涨幅
RS_60 = 板块60日涨幅 - 基准60日涨幅
```

基准可以用：

```text
沪深300
中证全指
创业板指
中证1000
万得全A
```

判断：

```text
RS_20 > 0：强于市场
RS_20 排名前20%：强势方向
RS_20 排名前10%：核心强势方向
```

---

### 指标 2：板块均线状态

```text
板块指数 > MA20：短期强
板块指数 > MA50：中期强
板块指数 > MA150：长期强
MA20 > MA50：趋势向上
```

评分：

```text
板块指数 > MA20：+1
板块指数 > MA50：+1
板块指数 > MA150：+1
MA20 > MA50：+1
MA50 > MA150：+1
```

满分 5 分。

---

## B. 广度 Breadth

看是不是一批股票一起强，而不是孤立个股。

### 指标 1：新高数量

```text
NH_20 = 板块内创20日新高个股数 / 板块股票总数
NH_60 = 板块内创60日新高个股数 / 板块股票总数
NH_120 = 板块内创120日新高个股数 / 板块股票总数
```

判断：

```text
NH_60 > 10%：板块有明显强度
NH_60 > 20%：主线特征明显
NH_60 连续上升：资金扩散
```

---

### 指标 2：均线上方比例

```text
Above_MA20 = 板块内收盘价 > MA20 的股票比例
Above_MA50 = 板块内收盘价 > MA50 的股票比例
Above_MA150 = 板块内收盘价 > MA150 的股票比例
```

判断：

```text
Above_MA20 > 60%：短期广度好
Above_MA50 > 50%：中期广度好
Above_MA150 > 40%：长期结构好
```

---

### 指标 3：上涨家数比例

```text
Advancing_Ratio_5 = 最近5日上涨股票比例
Advancing_Ratio_20 = 最近20日上涨股票比例
```

这个可以判断资金是否扩散。

---

## C. 持续性 Persistence

主线必须有持续性，不是一日游。

### 指标 1：连续强势天数

```text
Strong_Day = 板块日涨幅 > 基准日涨幅 且 板块成交额 > 20日均额

Persistence_5 = 最近5天 Strong_Day 数量
Persistence_10 = 最近10天 Strong_Day 数量
Persistence_20 = 最近20天 Strong_Day 数量
```

判断：

```text
最近5天强势 >= 3天：题材活跃
最近10天强势 >= 6天：主线候选
最近20天强势 >= 12天：强主线
```

---

### 指标 2：回调后修复

```text
Recovery = 板块从最近回撤低点反弹幅度 / 前一轮回撤幅度
```

简单一点可以用：

```text
板块回调后，是否重新站回 MA20
板块是否重新创20日新高
龙头是否重新创高
```

判断：

```text
回调不破 MA20：强
破 MA20 后 3–5 日内收回：仍强
破 MA50 且无法收回：主线退潮
```

---

## D. 龙头性 Leadership

没有龙头，不叫主线。

### 指标 1：龙头强度

你可以先定义方向内 Top N 龙头：

```text
Leader candidates =
最近60日涨幅排名前5
且成交额排名前30%
且价格在MA20/MA50之上
```

然后看：

```text
Leader_RS = 龙头60日涨幅 - 基准60日涨幅
Leader_NH = 龙头是否创60/120/250日新高
Leader_Drawdown = 龙头距20日高点回撤
```

判断：

```text
龙头创60日新高：强
龙头创120日新高：很强
龙头创历史新高：极强
龙头回撤 < 10%：趋势健康
龙头跌破 MA20：短期警告
龙头跌破 MA50：主线降级
```

---

### 指标 2：中军是否稳定

A股主线通常不只有妖股，还要看中军。

中军特征：

```text
成交额大
市值较大
机构参与度高
走势稳定
能代表板块方向
```

量化：

```text
方向内成交额前3股票是否在 MA20 之上
方向内成交额前3股票是否强于指数
方向内成交额前3股票是否接近阶段新高
```

如果只有小票乱涨，中军不动，要谨慎。

---

## E. 成交额 Liquidity

主线一定有资金容量。

### 指标 1：成交额占比

```text
Turnover_Share = 方向成交额 / 全市场成交额
```

判断：

```text
成交额占比上升：资金流入
成交额占比连续上升：主线强化
成交额占比极高但价格滞涨：拥挤风险
```

---

### 指标 2：成交额放大

```text
Volume_Ratio = 今日方向成交额 / 过去20日平均成交额
```

判断：

```text
> 1.2：活跃
> 1.5：明显放量
> 2.0：强烈资金关注
```

但注意：

```text
放量上涨 = 好
放量滞涨 = 风险
放量下跌 = 退潮信号
```

---

## F. 抗跌与修复 Resilience

主线不是永远不跌，而是跌了有人买回来。

### 指标 1：下跌日抗跌

```text
Market_Down_Day = 基准指数跌幅 < -0.5%

Resilience = 市场下跌日中，板块跑赢基准的比例
```

判断：

```text
过去10个市场下跌日，板块有6次以上跑赢指数 = 抗跌强
```

---

### 指标 2：反弹日领涨

```text
Market_Up_Day = 基准指数涨幅 > 0.5%

Leadership_Up = 市场上涨日中，板块跑赢基准的比例
```

真正主线通常是：

```text
跌时抗跌
涨时领涨
```

# 6. 四类状态的量化定义

现在把它们整合起来。

---

## 1. 热点量化定义

一个方向满足：

```text
今日涨幅排名前10%
且成交额比过去20日均值 > 1.5
且涨停/大阳线数量明显增加
但过去20日RS不一定强
```

可以定义为热点。

### Hot Spot Score

```text
Hot_Score =
40% 今日涨幅排名
+ 30% 今日成交额放大
+ 20% 涨停/大阳线数量
+ 10% 新闻/催化剂标签
```

实战判断：

```text
Hot_Score 高，但 Persistence 低 = 热点
```

特点：

```text
可以观察
不宜追高
等待是否升级为题材
```

---

## 2. 题材量化定义

一个方向满足：

```text
过去5–10日 RS > 0
最近5日中至少3日跑赢指数
成交额持续高于20日均值
板块内至少2–3只股票明显走强
但60日持续性和龙头稳定性还不充分
```

可以定义为题材。

### Theme Score

```text
Theme_Score =
30% RS_5 / RS_10
+ 25% 成交额放大
+ 20% 板块新高数量
+ 15% 龙头短期强度
+ 10% 催化剂清晰度
```

实战判断：

```text
Theme_Score 连续3天高 = 活跃题材
Theme_Score 连续5–10天高 = 主线候选
```

---

## 3. 主线量化定义

一个方向满足：

```text
RS_20 排名前20%
RS_60 排名前30%
板块指数在 MA20 和 MA50 之上
方向内 NH_60 明显增加
至少2只核心龙头创60日/120日新高
成交额占比持续上升
回调后能重新走强
```

可以定义为主线。

### Leadership Score

```text
Leadership_Score =
25% 板块相对强度
+ 20% 龙头强度
+ 20% 广度/新高数量
+ 15% 成交额占比
+ 10% 持续性
+ 10% 抗跌修复
```

状态判断：

```text
Leadership_Score > 70：主线
Leadership_Score > 80：强主线
Leadership_Score 连续10日 > 70：确认主线
Leadership_Score 跌破50：主线降级
```

---

## 4. 大周期主线量化定义

大周期主线不能只靠短期价格，要加入长期趋势和基本面/产业变量。

一个方向满足：

```text
过去1–3年产业需求持续增长
政策/技术/资本开支支持
方向内多轮行情反复出现
长期龙头仍能不断创新高或业绩兑现
长期指数/板块相对市场保持强势
```

量化可以用：

```text
Secular_Score =
30% 产业增长指标
+ 25% 3年相对强度
+ 20% 龙头长期趋势
+ 15% 盈利/订单/收入兑现
+ 10% 政策/资本开支支持
```

但对你的短线趋势系统，大周期主线不要用于买卖，只用于：

```text
维护长期股票池
理解资金为什么反复回流
识别未来可能重新启动的方向
```

# 7. 一个完整的状态分类模型

你可以每天给每个方向打三个分：

```text
Hot_Score：短期热度
Theme_Score：题材强度
Leadership_Score：主线强度
```

再加一个长期：

```text
Secular_Score：大周期属性
```

然后分类。

## 状态分类

```text
热点：
Hot_Score > 70
Theme_Score < 60
Leadership_Score < 50

题材：
Theme_Score > 65
Leadership_Score < 70
且持续3天以上

主线候选：
Theme_Score > 70
Leadership_Score 60–70
且持续5天以上

主线：
Leadership_Score > 70
且持续10天以上

强主线：
Leadership_Score > 80
且龙头持续新高

大周期主线：
Secular_Score > 70
不要求短期Leadership_Score一直高
```

# 8. 状态迁移规则

这是非常适合编码的部分。

```text
热点 → 题材：
连续3天保持高成交额，并且板块内多只股票继续走强

题材 → 主线候选：
过去10天跑赢指数，龙头创阶段新高，板块新高数量增加

主线候选 → 主线：
过去20天相对强度排名靠前，回调后重新走强，龙头持续带队

主线 → 退潮：
龙头跌破MA20后无法收回，板块新高数量下降，成交额放大但价格滞涨

主线 → 大周期主线：
多轮行情反复出现，并且产业/业绩持续兑现
```

# 9. 主线生命周期量化

你可以把主线分成 5 个阶段。

## 阶段 1：萌芽期

```text
Hot_Score 上升
Theme_Score 刚突破60
Leadership_Score < 60
少数股票创新高
```

操作：

```text
观察，不重仓
```

---

## 阶段 2：确认期

```text
Theme_Score > 70
Leadership_Score 60–70
龙头创60日新高
板块成交额放大
板块新高数量增加
```

操作：

```text
开始重点关注系统信号
```

---

## 阶段 3：主升期

```text
Leadership_Score > 80
龙头持续新高
板块广度扩大
成交额占比上升
回调不破MA20
```

操作：

```text
最适合你的 Day-2 系统
优先买主线内强个股
```

---

## 阶段 4：分化期

```text
Leadership_Score 仍高
但 Breadth 开始下降
二三线补涨增多
龙头涨幅变慢
板块成交额高位震荡
```

操作：

```text
只买龙头和最强分支
减少弱补涨
```

---

## 阶段 5：退潮期

```text
龙头跌破MA20/MA50
板块新高数量下降
成交额放大但价格不涨
补涨股大跌
Leadership_Score 跌破50
```

操作：

```text
停止新开仓
只执行退出规则
```

# 10. 适合你系统的最小可行版本

你不需要一开始做得太复杂。

先做一个 **MVP 主线雷达** 就够了。

每个方向每天计算 6 个指标：

```text
1. RS_20：20日相对强度
2. RS_60：60日相对强度
3. NH_60：60日新高股票比例
4. Above_MA20：站上20日线比例
5. Volume_Ratio：成交额放大倍数
6. Leader_Status：龙头是否在20日高点附近
```

然后打分：

```text
Sector_Score =
25% RS_20排名
+ 20% RS_60排名
+ 20% NH_60
+ 15% Above_MA20
+ 10% Volume_Ratio
+ 10% Leader_Status
```

分类：

```text
Score > 80：强主线
70–80：主线
60–70：主线候选 / 强题材
50–60：题材
<50：普通方向
```

# 11. 和你的 Day-2 系统如何结合

你的系统平均持股 7.5 天，所以主线因子不要过重。

我建议：

```text
最终信号排序 =
75% 个股交易信号质量
+ 25% 赛道/主线分数
```

个股交易信号质量包括：

```text
趋势多头
突破强度
Day-2回踩质量
成交量
风险距离
指数环境
```

主线分数包括：

```text
所属方向是否主线
所属方向是否有龙头
所属方向是否在扩散
所属方向是否资金回流
```

核心原则：

> **主线只负责排序，不负责替代入场。**

# 12. 最关键的避免事项

## 错误 1：把热点当主线

```text
当天涨停潮
媒体很热
成交额突然放大
```

这只是热点，不一定是主线。

必须等：

```text
持续性
龙头
扩散
回调后回流
```

---

## 错误 2：把大周期主线当买入理由

```text
AI 是未来
半导体国产替代是未来
机器人是未来
```

都不等于今天可以买。

对你来说：

```text
大周期主线 = watchlist
当前主线 = priority
系统信号 = entry
退出规则 = discipline
```

## 错误 3：主线退潮后还用故事硬扛

主线退潮时最常见的心理是：

```text
长期逻辑还在
只是短期调整
龙头以后还会回来
```

可能是真的，但你的系统不是长期价值系统。

如果：

```text
龙头破MA20
板块新高数量下降
板块成交额放大但不涨
Day-2信号失败率上升
```

就应该降级。

# 13. 最终定义汇总

你可以直接把下面这段写进你的交易系统文档。

```text
热点 Hot Spot：
1–3天内由消息或情绪驱动的短期资金集中方向。
量化特征是单日涨幅高、成交额放大、涨停/大阳线增加，但持续性未验证。

题材 Theme：
有清晰叙事或催化剂，并在3–15个交易日内持续活跃的交易方向。
量化特征是短期相对强度为正、成交额持续放大、板块内多只股票走强。

主线 Market Leadership：
数周到数月内持续强于市场、资金反复回流、龙头持续创新高、板块内部扩散的核心方向。
量化特征是20/60日相对强度靠前、龙头创新高、新高数量增加、成交额占比上升、回调后能修复。

大周期主线 Secular Trend：
由长期产业变革、技术革命、政策战略驱动的多年级别方向。
量化特征是长期产业增长、长期相对强度、龙头长期趋势和业绩兑现，但不直接作为短线买入依据。
```

最简洁的交易版：

> **热点看一天，题材看一周，主线看一月，大周期主线看几年。**

对你的系统：

> **热点用于预警，题材用于观察，主线用于排序，大周期主线用于建池。**
